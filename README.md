## 三个阶段（按中国时间自动切换）

页面在三天里长得不一样，**跨日会自己切换，粉丝不用刷新**：

| 日期 | 阶段 | 信封 | 牵红线 |
|---|---|---|---|
| **823 及之前** | `teaser` | 52 封**全部显示**，都是预告态（未拆封、无完整内容） | ✅ 有 |
| **824** | `reveal` | **只挂已解锁的**：按时间表 00:24 第一封 …… 23:30 满 52 封。预告信封不出现 | ❌ 无 |
| **825 及之后** | `archive` | 52 封全开 | ❌ 无 |

824 当天信封少的时候会**居中挂在树冠下**，不会孤零零缩在左上角。

|---|---|

`?phase=` 可以和 `?demo=1` 组合。`?slot=N` = 假装前 N+1 封已开（超出总数按总数算），只在 `demo + reveal` 下生效。
后台「预览粉丝页」按钮走的是 `?preview=`。

```bash

```

## 解锁规则

`slot` = **当天第几分钟开启**（中国时区），按客户时间表：0:24、1:09、1:30 … 23:30。
后台编辑弹窗里可以直接改时间（HH:MM），拖动排序会沿用整份时间表重新对号。

- 824 当天 00:24 → 第 1 封解锁，其余只有预告
- …… 23:30 → 52 封全解锁
- **823 及之前**：全部只显示预告（牵红线只弹表情包，不解锁内容）
- **825 之后**：全开

判定在**服务端**做（`public_get_letters()`），改本机时间没用。

## 后台怎么用

1. 打开 `admin.html`，输入管理密钥
2. **作者页** → 先把作者建好（名字 / 头像 / 一句话介绍）
3. **信件页** → 「初始化 52 封」一次性建好 52 个时段
4. 逐封填：
   - **开启时间**：直接填 HH:MM（撞到别的信会自动对调）
   - **物料作者**：下拉选（牵红线用这个配对）
   - **预告**：未解锁时粉丝看到的（预告图会自动打码模糊）
   - **完整内容**：文字 / 影片 / 图片 / 链接，可混合
   - **上线**开关：打开才会出现在粉丝页
5. 「预览粉丝页」按钮 → 全解锁验收内容

### 素材怎么放

| 类型 | 方式 | 上限 |
|---|---|---|
| **图片** | 上传（拖进去 / 点击选择）**或**贴网址，两种都行 | 15MB |
| **影片** | 只贴网址（YouTube / Bilibili / mp4 直链） | — |
| **作者头像** | 同图片，上传或贴网址 | 15MB |

图片上传到 Supabase Storage：

- 文件名带**随机串**，粉丝猜不到未解锁素材的网址
- 点「移除」会同时把 Storage 里的文件删掉，不占空间
- **上传完还要点「保存这封」** —— 上传只是把文件放上去，绑定到信件要保存
- 上传和贴网址是二选一：传了文件，网址栏会自动收起

> 容量估算：52 封 × 15MB ≈ 720MB，在 Supabase 免费版 1GB 额度内。

## 牵红线（挂牌场景 · 红线常牵）

- **只在 823 预告期出现**，824 和 825 自动隐藏
- 入口：粉丝页底部「🔗 牵红线」按钮，或 `?phase=teaser#play` 直接打开
- 结构：1 作者 = 1 作品，52 对拆成 **13 关、每关 4 对**
- 答错**不结束本局**：红线绷断、弹一次「牵错啦」表情包，两张卡放回去继续牵（不用把错的重新连回对的），直到本关全对
- **进度存 sessionStorage**：关掉弹窗再打开、刷新页面都接着上次的关卡继续；关掉分页就清空。通关或点「再玩一次」会重新随机
- 场景（默认左右布局；`?layout=td` 可切上下布局）：
  - 左边一根竖的樱花枝，作品挂牌用小绳**系在枝上**、微微摇晃
  - 右边一列作者名牌；作品卡带类型 chip、作者带身份，可以推理
- 玩法：点一个挂牌 → 点它的作者（两边都可以先点）
  - 选中 → 挂牌探出一截**摆动的红线头**
  - 牵对 → 红线画过去打结、**一直连着不消失**，并弹出一张**答对表情包**
    （完整内容不提前给，一律留到 824 按时间表解锁）
  - **牵错 → 红线绷断，本局结束**（月老画面显示已牵根数），
    可「再牵一次」从第 1 关重来，关卡重新随机
- 每关 4 对、每局随机组合；作者名牌统一用客户提供的头像
- **表情包**：答对弹 A 份、答错弹 B 份，两份分类不同，每次随机（抽签袋式，一轮抽完才重复）
  - 文件放 `assets/stickers/correct/` 与 `assets/stickers/wrong/`
  - 再把路径加进 `config.js` 的 `STICKERS_CORRECT` / `STICKERS_WRONG` 清单
  - 支持 mp4 / gif / png / jpg；mp4 会静音循环自动播
  - 清单留空时自动退回 emoji（🎈 / 🥀），不会破版
- 关卡进度 = 顶部一排小红点；13 关全牵完 → 烟花
- **不储存进度**（刷新即重来），符合需求

## 兼容性

手机优先，同时兼顾电脑：

- 信封网格 `auto-fill`，手机 4 列、电脑 7 列自动铺
- 牵红线一关只有 6 对，弹窗高度贴合内容，红线在场景内绘制、滚动缩放不错位
- 作者卡片窄屏竖排（头像在上）、≥620px 横排
- `env(safe-area-inset-*)` 适配刘海屏
- 弹窗打开时背景加深模糊，减轻视觉负担
