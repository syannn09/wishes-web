## 三个阶段（按中国时间自动切换）

页面在三天里长得不一样，**跨日会自己切换，粉丝不用刷新**：

| 日期 | 阶段 | 信封 | 连连看 |
|---|---|---|---|
| **823 及之前** | `teaser` | 48 封**全部显示**，都是预告态（未拆封、无完整内容） | ✅ 有 |
| **824** | `reveal` | **只挂已解锁的**：00:00 一封、00:30 两封 …… 23:30 满 48 封。预告信封不出现 | ❌ 无 |

824 当天信封少的时候会**居中挂在树冠下**，不会孤零零缩在左上角。


## 解锁规则

`slot = 小时 × 2 + (分钟 >= 30 ? 1 : 0)`，**中国时区**。

- 824 当天 00:00 → 第 1 封解锁，其余 47 封只有预告
- 00:30 → 前 2 封解锁，其余 46 封只有预告
- …… 23:30 → 48 封全解锁
- **非 824 当天**：全部只显示预告

判定在**服务端**做（`public_get_letters()`），改本机时间没用。

## 后台怎么用

1. 打开 `admin.html`，输入管理密钥
2. **作者页** → 先把作者建好（名字 / 头像 / 一句话介绍）
3. **信件页** → 「初始化 48 封」一次性建好 48 个时段
4. 逐封填：
   - **解锁时段**：0~47
   - **物料作者**：下拉选（连连看用这个配对）
   - **预告**：未解锁时粉丝看到的（预告图会自动打码模糊）
   - **完整内容**：文字 / 影片 / 图片 / 链接，可混合
   - **上线**开关：打开才会出现在粉丝页
5. 「预览粉丝页」按钮 → 全解锁验收内容

### 素材怎么放

| 类型 | 方式 | 上限 |
|---|---|---|
| **图片** | 上传（拖进去 / 点击选择）**或**贴网址，两种都行 | 15MB |
| **影片** | 只贴网址（YouTube / Bilibili / mp4 直链） | — |
| **作者头像** | 同图片，上传或贴网址 | 15MB |

图片上传到 Supabase Storage：

- 文件名带**随机串**，粉丝猜不到未解锁素材的网址
- 点「移除」会同时把 Storage 里的文件删掉，不占空间
- **上传完还要点「保存这封」** —— 上传只是把文件放上去，绑定到信件要保存
- 上传和贴网址是二选一：传了文件，网址栏会自动收起

> 容量估算：48 封 × 15MB ≈ 720MB，在 Supabase 免费版 1GB 额度内。

## 连连看（分关消除式）

- **只在 823 预告期出现**，824 和 825 自动隐藏
- 入口：粉丝页底部「🔗 连连看」按钮，或 `?phase=teaser#play` 直接打开
- 结构：1 作者 = 1 作品，48 对拆成 **8 关、每关 6 对**（一屏放得下，不用滚动）
- 玩法：点一个作品 → 点它的作者（两列都可以先点）
  - 配对成功 → 两张卡**化成樱花瓣飘走**
  - 配错 → 抖动一下，无惩罚
- 作品卡带类型 chip（插画/影片/文字…），作者卡带身份（画手/剪辑…），可以推理
- **没有任何连线** —— 之前拖线画 48 条金线会变蜘蛛网，已整个换掉
- 一关清完自动进下一关；8 关全清 → 烟花 + 「再玩一次」
- **不储存进度**（刷新即重来），符合需求

## 兼容性

手机优先，同时兼顾电脑：

- 信封网格 `auto-fill`，手机 4 列、电脑 7 列自动铺
- 连连看两栏共用一个滚动容器，保证物料和作者永远同屏可见
- 作者卡片窄屏竖排（头像在上）、≥620px 横排
- `env(safe-area-inset-*)` 适配刘海屏
- 弹窗打开时背景加深模糊，减轻视觉负担
